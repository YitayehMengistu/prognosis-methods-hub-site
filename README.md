# Prognosis Methods Hub

This repository publishes the static catalogue on GitHub Pages. The release includes the searchable catalogue, methods guides and reference downloads. See the site's About page for its licences and curation methods.

To publish an updated catalogue, replace `catalogue.zip` and `catalogue.zip.sha256` together. The ZIP must contain `index.html` and its assets at the archive root. The deployment workflow verifies the checksum before publishing.
